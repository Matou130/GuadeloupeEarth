Un archipel entier, à explorer au volant

Guadeloupe Earth est un mod pour BeamNG.drive qui vise à rendre l’archipel de la Guadeloupe explorable dans le jeu, grâce à la génération géographique et aux technologies du projet open source BeamNG.Earth.

C’est un développement communautaire, en évolution : le code est public, et chacun peut tester, signaler un problème ou proposer une amélioration.

  • Les routes et les chemins de la Guadeloupe
  • Les reliefs et les paysages
  • Les bâtiments
  • La végétation
  • Les textures et images aériennes
  • L’exploration libre de différentes zones de l’archipel

Les îles de Guadeloupe

Six territoires visés par le projet. Ce sont des objectifs : aucune zone n’est annoncée comme terminée ou disponible dans le mod.

Ces vues sont des cartes dessinées d’après les contours Natural Earth (domaine public), remplacées par de l’imagerie satellite lorsqu’elle se charge. Ce ne sont pas des captures du mod ni du jeu.

Imagerie satellite : EOxCloudless https://cloudless.eox.at by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2016 & 2017), licence CC BY 4.0.

Questions fréquentes

Qu’est-ce que Guadeloupe Earth ?

Un mod communautaire pour BeamNG.drive qui vise à rendre l’archipel de la Guadeloupe explorable dans le jeu. Il s’inspire du projet open source BeamNG.Earth. Il est en cours de développement.

Quel jeu est nécessaire ?

BeamNG.drive. Le mod ne fonctionne pas sans le jeu.

Comment installer le mod ?

La procédure d’installation sera indiquée avec chaque version publiée sur la page GitHub Releases. Tant qu’aucune version n’est disponible, il n’y a rien à installer.

Le mod fonctionne-t-il sans Internet ?

C’est un objectif. Le mode hors ligne utilisera les données déjà mises en cache : une zone jamais téléchargée ne pourra pas être générée entièrement. Cette fonction sera annoncée comme disponible seulement après avoir été intégrée et testée dans une version publiée.

Toutes les îles sont-elles disponibles ?

Non, pas à ce stade. Les six territoires sont visés, mais aucune zone n’est annoncée comme terminée. L’état de chacune sera précisé dans les notes de version.

Comment signaler un bug ?

Ouvrez un ticket sur GitHub Issues, en décrivant ce que vous avez fait, ce qui s’est passé et votre version du jeu.

Comment participer au projet ?

Testez le mod, signalez les bugs, proposez des améliorations, partagez vos captures d’écran ou contribuez au code depuis le dépôt GitHub.
